SUR VOTRE APPAREIL

Vos photos et vidéos restent ici.

NOFACE les traite sur votre appareil. Le code de l’application ne les envoie à personne. Pour fonctionner, elle télécharge des outils depuis d’autres sites. Le résultat reste dans cette page jusqu’à ce que vous changiez de fichier ou fermiez la page.

Quels autres sites sont contactés ?

Au chargement, NOFACE reçoit une partie de son programme depuis jsDelivr et le fichier qui l’aide à reconnaître les visages depuis Hugging Face. Ces sites savent que vous avez téléchargé ces outils, mais le code de NOFACE ne leur envoie pas vos photos ou vidéos. Votre navigateur peut garder ces outils pour la prochaine fois. Comme une partie du programme vient d’un autre site, il faut aussi lui faire confiance.
